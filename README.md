# Student Degree Organiser Application

A smart and interactive **Python** script designed to automatically classify student grades based on their academic degrees using multi-conditional logical operators.

## Features
- **Dynamic Grading System:** Evaluates inputs and rewards students with standard academic grades (`A`, `B`, `C`, or `F`).
- **Robust Math Handling:** Converts inputs into floating-point numbers (`float`) to seamlessly accept decimal scores.
- **Multi-Conditional Logic:** Efficiently structures logic using Python's `if-elif-else` branches for precise decision-making.

## Technologies Used
- Python 3
